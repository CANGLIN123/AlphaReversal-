# AlphaReversal — A-Share Multi-Factor Quantitative Strategy

基于 **KDJ 超卖 + 量价关系 + 反弹弹性预测** 的 A 股多因子选股策略。

## 策略逻辑

### 四层选股漏斗
```
L1: 长期趋势向上 (price > MA60 & BBI > MA60)
L2: 60日内曾极度超卖 (J_min < 15)
L3: 前期放量异动 (爆量阳线 或 连续堆量)
L4: 当天小K线企稳 (|日涨跌幅| ≤ 2%)
```

### 十因子打分体系
| 因子 | 权重 | 逻辑 |
|------|:----:|------|
| 超卖深度 | 14% | J_60d_min 越低越好 |
| 缩量程度 | 13% | 抛压衰竭信号 |
| 小K线企稳 | 8% | 不在大跌中入场 |
| 放量异动 | 12% | 主力资金进场痕迹 |
| 反转确认 | 11% | J拐头+缩量+小K线 |
| BBI趋势 | 10% | 多空方向确认 |
| MA60贴近 | 7% | 回调到位程度 |
| 行业热度+质量 | 12% | 行业轮动+PE/ROE |
| 🆕 反弹弹性 | 10% | 预测反弹幅度 |
| Amihud弹性 | 3% | 流动性因子 |

### 因子 IC/IR
| 因子 | IC | IR | 评价 |
|------|:---:|:---:|:---:|
| Amihud 非流动性 | 0.127 | 1.996 | 🔥极强 |
| 反弹弹性 | 0.020 | 0.309 | 强 |
| 缩量程度 | 0.006 | 0.103 | 中等 |

### 风控体系
- **6 层卖出信号**: ATR 硬止损 → 移动止盈 → BBI趋势保护 → 时间止损 → 放量阴线 → 动态换仓
- **市场宽度择时**: 全市场 MA20 站上率判断牛熊，熊市自动空仓
- **动态仓位**: 牛市高分重仓 50%，熊市 0%；反弹弹性修正仓位乘数
- **行业中性化**: 行业内 z-score 标准化，单行业 ≤ 3 只

## 快速开始

```bash
# 1. 安装依赖
pip install tushare pandas numpy matplotlib scipy

# 2. 配置 tushare token
# 编辑 src/data_engine.py: TUSHARE_TOKEN = "你的token"
# 注册获取: https://tushare.pro

# 3. 快速测试 (20只股票, ~1分钟)
python run.py --pool top20 --start 20230101

# 4. 完整回测 (全市场 >50亿, ~30分钟)
python run.py --pool hs300 --start 20200101 --end 20251201

# 5. 因子 IC 分析
python tools/ic_quick.py

# 6. 蒙特卡洛显著性检验
python tools/monte_carlo.py
```

## 核心设计亮点

- **避免前视偏差**: ExecutionSimulator 用 T+1 开盘价成交，信号用 .shift(1) 滞后
- **市场自适应**: 6 种市场状态 × 不同参数组合
- **向量化回测**: pandas 矩阵运算，500 只 × 5 年 ≈ 秒级
- **Walk-forward 验证**: 训练窗 2 年 + 测试窗 1 年，滚动样本外检验
- **反弹弹性因子**: 原创的"下跌特征→反弹幅度"预测因子，IC=0.020, IR=0.309
